# Personal Portfolio & Technical Hub
---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Welcome to my personal technical portfolio repository. This single-page application serves as my professional digital storefront, showcasing the intersection of **Growth Automation (Technical VA Operations)** and **Defensive Cybersecurity (Security Research)**. 

Live Deployment Link: `https://hansec-technology-dot.github.io/`

## Core Architecture & Design Philosophy
---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
The site's layout is engineered from the ground up for elite performance, clean responsiveness, and sleek, luxury aesthetics:
* **The Palette:** High-contrast premium dark space (`#0A0A0C`) balanced against precise luxury gold accents (`#D4AF37`) to keep visual focus sharp and professional.
* **Typography Engine:** Uses asynchronous font pre-connection headers linking `Inter` for clean, readable technical text, and `Playfair Display` for bold, narrative headings.
* **Performance Optimizations:** Zero bulky framework overhead. Built using vanilla `HTML5`, native utility `CSS3` Custom Properties (variables), and modern multi-device responsive break-coding (`@media` styling blocks).
